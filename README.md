# FluidNexus TCC 2

Repositório do Trabalho de Conclusão de Curso 2 de Felipe Augusto Sousa de Almada.

O projeto investiga a reconstrução tridimensional e a evolução temporal de fluidos a partir dos conjuntos de dados utilizados pelo FluidNexus. Os experimentos considerarão FluidNexus-Smoke, FluidNexus-Ball e ScalarReal/ScalarFlow, com resultados visuais por frame e avaliação quantitativa.

## Estrutura inicial

- `configs/`: configurações dos experimentos.
- `data/`: instruções e arquivos locais dos datasets, sem versionar os dados brutos.
- `docs/`: documentação do TCC e notas metodológicas.
- `results/`: tabelas, figuras e resultados dos experimentos.
- `src/`: código-fonte do pipeline de reconstrução e avaliação.

## Dataset principal

- FluidNexus: https://yuegao.me/FluidNexus/
- Arquivos: https://huggingface.co/datasets/yuegao/FluidNexusDatasets
